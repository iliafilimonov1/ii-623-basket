# Как запустить проект локально

Инструкция для студентов, у которых ещё не установлен Node.js. Команды выполняются **из папки проекта** `basket-623`.

Ниже сначала объясняется, что значат слова из инструкции, затем идут шаги запуска.

---

## Что такое Node.js и зачем он нужен

**Node.js** — это программа, которая запускает язык JavaScript **на компьютере**, а не только в браузере.

Обычный JavaScript живёт в Chrome, Safari и других браузерах: кнопки, страницы, корзина. Браузер умеет показывать сайт, но **не умеет** сам скачивать библиотеки, поднимать локальный сервер разработки и собирать проект из исходников. Для этого нужен Node.js: он даёт JavaScript доступ к файлам на диске, к сети и к командам вроде `npm`.

Для этого проекта Node.js нужен не как «сервер интернет-магазина в интернете», а как **инструмент разработчика** на вашем компьютере:

- скачать библиотеки (React, Vite, Tailwind и другие);
- запустить локальную копию сайта командой `npm run dev`;
- позже собрать проект для публикации (`npm run build`).

Без Node.js команды `npm` и `node` не существуют: система пишет «команда не найдена» или «не является внутренней или внешней командой».

Вместе с Node.js почти всегда ставится **npm** (Node Package Manager) — менеджер пакетов. Это каталог готовых библиотек: по списку в файле `package.json` npm скачивает нужный код.

Проверка, что всё установлено:

```bash
node -v
npm -v
```

Должны появиться номера версий, например `v22.x.x` и `10.x.x`.

**Коротко:** браузер показывает сайт пользователю. Node.js помогает этот сайт **собрать и запустить у вас на компьютере**.

## Что такое командная строка (терминал)

**Командная строка**, **терминал** или **консоль** — это окно, где компьютером управляют **текстом**, а не кнопками.

В Finder или Проводнике вы кликаете по папкам. В терминале вы пишете команды:

```bash
cd /путь/к/папке/basket-623
ls
```

- `cd` — перейти в папку;
- `ls` — показать, что внутри (на Windows в `cmd` то же самое делает `dir`).

Установка зависимостей и запуск сервера разработки — это программы **без отдельного красивого окна**. Их запускают командами. Поэтому в инструкции постоянно говорится «откройте терминал».

Где взять терминал:

- на **macOS** — приложение **Терминал**;
- на **Windows** — **cmd** или **PowerShell**;
- в **Cursor / VS Code** — встроенный терминал: меню **Terminal → New Terminal**.

Важно не просто открыть терминал, а оказаться **в папке проекта**. Команды `npm install` и `npm run dev` ищут файл `package.json` **в текущей папке**. Если вы стоите в `Downloads` или на рабочем столе, команда упадёт с ошибкой вроде `ENOENT ... package.json`.

Проверка: после `ls` (или `dir`) в списке должны быть `package.json`, `index.html`, `vite.config.js` и папка `src`. Если их нет — вы не в `basket-623`, сделайте `cd` ещё раз.

Пока работает `npm run dev`, **окно терминала нельзя закрывать**: сервер живёт в этом процессе. Остановка — `Ctrl + C` в том же окне.

---

## Что такое Cursor и VS Code

**VS Code** (Visual Studio Code) — бесплатный редактор кода от Microsoft. В нём открывают папку проекта, правят файлы `.jsx` / `.js` / `.css`, видят дерево файлов слева и запускают терминал внутри редактора.

**Cursor** — это редактор **на базе VS Code**, плюс встроенный ИИ-помощник (чат, правки кода). Для запуска этого проекта Cursor и VS Code делают одно и то же:

- открывают папку `basket-623`;
- показывают исходники;
- дают встроенный терминал, который сразу стартует в корне проекта.

Это **не** Node.js и **не** браузер. Редактор только помогает писать и запускать команды. Сайт в итоге открывается в обычном браузере по адресу `http://localhost:5173/`.

Как открыть проект:

1. **File → Open Folder** (Файл → Открыть папку).
2. Выберите папку `basket-623`, не вложенную `src`.
3. **Terminal → New Terminal** — терминал уже будет в нужной директории.

Можно работать и без Cursor/VS Code: править файлы в любом редакторе, а команды запускать в системном Терминале. Для учёбы удобнее редактор с терминалом внутри.

## Что такое установка зависимостей

**Зависимости** — готовые библиотеки, без которых проект не запустится. Сами мы их не пишем: React рисует интерфейс, Vite поднимает сервер разработки, Tailwind даёт стили, `react-router-dom` — переходы между страницами, Swiper — слайдер на главной.

Список нужных пакетов лежит в файле `package.json` в корне проекта. Сам код библиотек **не кладут в git целиком**: его слишком много. В репозитории обычно есть только список, а файлы скачиваются на каждый компьютер отдельно.

Команда:

```bash
npm install
```

читает `package.json`, скачивает пакеты из интернета (реестр npm) и складывает их в папку **`node_modules`**. Пока качается, интернет нужен. Это делается **один раз** после клонирования/скачивания проекта (и снова — если список зависимостей изменился).

После успешной установки:

- появляется (или обновляется) папка `node_modules` — тысячи файлов, её руками не трогают;
- часто появляется `package-lock.json` — точные версии, чтобы у всех ставилось одинаково.

`npm install` **не запускает сайт**. Он только готовит инструменты. Сайт запускает следующая команда: `npm run dev`.

Если пропустить этот шаг, `npm run dev` обычно падает: не найден Vite, React и т.д.

## 1. Установите Node.js

Без Node.js команды `npm` не работают.

1. Откройте сайт [https://nodejs.org](https://nodejs.org).
2. Скачайте версию **LTS** (рекомендуемая) для своей системы: Windows или macOS.
3. Запустите установщик и пройдите шаги «Далее», ничего не меняя.
4. На Windows оставьте галочку **Add to PATH**, если она есть.
5. Полностью закройте все окна терминала и редактора (Cursor / VS Code) и откройте их заново — иначе система может не увидеть Node.js.

Проверка в терминале:

```bash
node -v
npm -v
```

Должны появиться номера версий, например `v22.x.x` и `10.x.x`. Если команда «не найдена» — перезагрузите компьютер и повторите проверку.

---

## 2. Откройте терминал именно в папке проекта

Проект должен запускаться **из каталога**, где лежат `package.json` и `src`.

### Windows

1. Откройте Проводник и зайдите в папку `basket-623`.
2. Кликните по пустому месту в адресной строке, введите `cmd` и нажмите Enter.
3. Откроется командная строка уже внутри папки проекта.

### macOS

1. Откройте **Терминал**.
2. Перейдите в папку проекта командой `cd` и перетащите папку `basket-623` в окно терминала — путь подставится сам:

```bash
cd /путь/к/папке/basket-623
```

### Cursor / VS Code

1. Откройте папку проекта в редакторе: **File → Open Folder**.
2. Меню **Terminal → New Terminal**.
3. Терминал сразу стартует в корне проекта.

Проверка, что вы в нужной папке:

```bash
ls
```

На Windows в `cmd`:

```bat
dir
```

В списке должны быть файлы `package.json`, `index.html`, `vite.config.js` и папка `src`. Если их нет — вы не в папке проекта, сделайте `cd` ещё раз.

---

## 3. Установите зависимости

В терминале, находясь в папке `basket-623`, выполните:

```bash
npm install
```

Дождитесь окончания. Появится папка `node_modules`. Интернет в этот момент нужен.

---

## 4. Запустите приложение

В той же папке выполните:

```bash
npm run dev
```

Не закрывайте это окно терминала, пока работаете с сайтом.

В выводе будет адрес локального сервера, обычно:

```text
Local: http://localhost:5173/
```

Если порт `5173` занят, Vite напишет другой, например `http://localhost:5174/` — открывайте тот, который показан.

Скопируйте ссылку в браузер или откройте её, зажав Ctrl (Windows) / Cmd (macOS) и кликнув по адресу в терминале.

---

## 5. Как остановить сервер

В окне, где запущен `npm run dev`, нажмите `Ctrl + C`. Чтобы запустить снова — снова `npm run dev` из папки проекта.

---

## Частые ошибки

| Что видите | Что сделать |
|---|---|
| `npm: command not found` / «не является внутренней командой» | Node.js не установлен или терминал не перезапускали после установки |
| `ENOENT ... package.json` | Команда запущена не из папки `basket-623` |
| Страница не открывается | Сервер не запущен или в браузере другой порт |
| Ошибка при `npm install` | Проверьте интернет и повторите команду |

После успешного запуска в браузере должна открыться главная страница маркетплейса Lumina.
