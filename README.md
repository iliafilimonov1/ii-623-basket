# Корзина товаров (Shopping Cart)

Простой и удобный проект корзины товаров для интернет-магазина, созданный на современном стеке веб-разработки.

---

## 🛠 Стек технологий

- **HTML5** — структура и семантическая разметка страниц.
- **CSS3 / Tailwind CSS** — современная утилитарная стилизация и адаптивный дизайн.
- **JavaScript (ES6+)** — интерактивность и логика приложения.
- **React** — библиотека компонентов для построения пользовательского интерфейса.
- **Zustand** — легкий и производительный менеджер состояния для управления корзиной (добавление, удаление, изменение количества товаров, подсчёт итоговой суммы).
- **Vite** — быстрый инструмент сборки и локальный сервер разработки.

## 📁 Структура проекта

```text
basket-623/
├── public/              # Статические файлы (иконка сайта favicon, векторные иконки)
│   ├── favicon.svg
│   └── icons.svg
├── src/                 # Исходный код приложения
│   ├── assets/          # Изображения, медиа-файлы и логотипы
│   ├── components/      # Компоненты интерфейса (каталог, карточки, корзина)
│   ├── store/           # Состояние Zustand (логика корзины и экшены)
│   ├── App.css          # Дополнительные стили компонента App
│   ├── App.jsx          # Главный React-компонент приложения
│   ├── index.css        # Глобальные стили и директивы Tailwind CSS
│   └── main.jsx         # Главная точка входа, монтирование React в DOM
├── .gitignore           # Список файлов и папок, игнорируемых Git
├── .oxlintrc.json       # Настройки быстрой проверки кода (Oxlint)
├── index.html           # Главный HTML-шаблон страницы
├── package.json         # Настройки проекта, скрипты и список зависимостей
├── package-lock.json    # Фиксация точных версий зависимостей
├── README.md            # Описание и документация проекта
└── vite.config.js       # Конфигурация сборщика Vite
```

## 🚀 Запуск проекта

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```

3. **Сборка для продакшена:**
   ```bash
   npm run build
   ```

4. **Предпросмотр собранного проекта:**
   ```bash
   npm run preview
   ```
