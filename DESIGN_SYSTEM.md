# Дизайн-система проекта «Корзина товаров» (Basket-623)

Данный документ является единым источником правды (Single Source of Truth) по визуальному языку, типографике, колористике, компонентам и архитектуре файлов для проекта.

Вся разработка новых страниц, модулей и UI-компонентов должна строго соответствовать правилам из этого документа.

---

## 1. Референс и визуальная эстетика

Визуальный язык вдохновлен минималистичными современными маркетплейсами (в стиле Airbnb, Apple, Stripe):
- Чистые светлые поверхности, мягкий контраст без резких черных заливок.
- Фокус на качественных фотографиях и читабельной информации.
- Плавные скругления (`rounded-2xl`, `rounded-full`).
- Деликатные полупрозрачные плашки-бейджи с эффектом размытия стекла (`backdrop-blur`).
- Легкие тени и аккуратные микро-взаимодействия (hover, active).

## 2. Типографика

### 2.1. Семейство шрифтов
- **Основной шрифт:** `Inter` (Google Fonts).
  - *Fallback:* `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`.
  - Подключен в `index.html` и зарегистрирован в `@theme` в `src/index.css`.
  - Отличается идеальной читаемостью на экранах любой плотности пикселей, высокой разборчивостью цифр и безупречной поддержкой кириллицы.

### 2.2. Веса шрифтов (Font Weights)
- `font-normal` (400) — второстепенный текст, даты, категории, описания товаров.
- `font-medium` (500) — интерактивные элементы, переключатели, фильтры, вторичные кнопки.
- `font-semibold` (600) — заголовки карточек, цены, плашки, бейджи, основной акцент в тексте.
- `font-bold` (700) — заголовки секций (H1, H2), итоговая сумма корзины, ключевые цифры.

### 2.3. Иерархия размеров (Type Scale)

| Назначение | Размер (Tailwind) | Вес | Цвет | Пример применения |
| :--- | :--- | :--- | :--- | :--- |
| **H1 (Главный заголовок)** | `text-2xl` / `sm:text-3xl` | `font-bold` (700) | `text-slate-900` | «Париж: популярное жилье», «Корзина» |
| **H2 (Заголовок блока)** | `text-xl` | `font-semibold` (600) | `text-slate-900` | Названия разделов, блоки оформления |
| **Заголовок карточки** | `text-[15px]` / `text-base` | `font-semibold` (600) | `text-slate-900` | «Квартира, Montmartre», «Кроссовки Nike» |
| **Цена товара** | `text-[15px]` / `text-base` | `font-semibold` (600) | `text-slate-900` | «Всего 5 793 ₽» |
| **Мета / Вторичный текст** | `text-sm` (14px) | `font-normal` (400) | `text-slate-500` | Даты, категория, цвет, размер |
| **Мелкие метки / Бейджи** | `text-xs` (12px) | `font-semibold` (600) | `text-slate-800` | «Выбор гостей», «Хит», рейтинг |
| **Микротекст** | `text-[11px]` | `font-medium` (500) | `text-slate-400` | Дополнительные подсказки, счетчик корзины |

## 3. Колористика и палитра

В приложении используется благородная сдержанная палитра на базе **Slate** с чистыми контрастными акцентами:

### 3.1. Основные нейтральные оттенки
- **Фон приложения (Canvas):** `#F8FAFC` (`bg-slate-50`) — мягче чистого белого, не утомляет зрение.
- **Поверхность карточек/модалок (Surface):** `#FFFFFF` (`bg-white`).
- **Основной текст:** `#0F172A` (`text-slate-900`) — глубокий графит вместо жесткого `#000000`.
- **Вторичный текст:** `#64748B` (`text-slate-500`) — подписи, мета-данные, даты, характеристики.
- **Третичный текст / Placeholder:** `#94A3B8` (`text-slate-400`).
- **Границы и разделители:**
  - Легкие: `#F1F5F9` (`border-slate-100`)
  - Стандартные: `#E2E8F0` (`border-slate-200`)
  - Активные/фокус: `#94A3B8` (`border-slate-400`)

### 3.2. Функциональные и акцентные цвета
- **Primary CTA (Кнопка действия):** `#0F172A` (`bg-slate-900`, hover: `bg-slate-800`, text: `text-white`) — премиальный минимализм.
- **Secondary CTA (Вторичная кнопка):** `bg-slate-100`, hover: `bg-slate-200`, text: `text-slate-800`.
- **Accent (Избранное / Скидки):** `#E11D48` (`text-rose-600`, `bg-rose-500`) — сердечко избранного, бейджи скидок.
- **Рейтинг (Stars):** `#0F172A` (`text-slate-900`) или `#F59E0B` (`text-amber-500`) для звезд.
- **Успех / В наличии:** `#10B981` (`text-emerald-600`, `bg-emerald-50`).
- **Удаление / Ошибка:** `#EF4444` (`text-red-600`, `hover:bg-red-50`).

### 3.3. Специальные поверхности
- **Бейдж «Выбор гостей»:** `bg-white/95 backdrop-blur-md text-slate-800 shadow-sm border border-white/60`.
- **Круглые кнопки (Стрелки слайдера, Избранное):** `bg-white/90 hover:bg-white text-slate-700 hover:text-slate-900 shadow-sm hover:shadow-md transition-all`.

## 4. Формы, скругления, тени и отступы

### 4.1. Скругления (Border Radius)
- **Изображения и карточки:** `rounded-2xl` (16px) — мягкий дружелюбный контур.
- **Кнопки действий и поля ввода:** `rounded-xl` (12px) или `rounded-full` для круглых/овальных пиллов.
- **Бейджи и круглые контролы:** `rounded-full` (9999px).
- **Модальные окна и дроверы корзины:** `rounded-3xl` (24px) или `rounded-2xl`.

### 4.2. Тени (Shadows)
- **Базовые карточки:** без агрессивных теней (`shadow-xs` или просто тонкий `border-slate-100`).
- **Кнопки-иконки над фото:** `shadow-sm`, при ховере `shadow-md`.
- **Всплывающая корзина / модалка:** `shadow-xl border border-slate-100`.

### 4.3. Сетка отступов (Spacing Grid)
- Основана на стандартном шаге Tailwind (4px / 8px).
- **Отступы между полями карточки:** `gap-1` (4px), `gap-1.5` (6px), `pt-3` (12px).
- **Сетка каталога:** `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-6`.
- **Контейнер страницы:** `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-8`.

## 5. Анатомия карточки товара (по референсу)

Карточка состоит из двух блоков:
1. **Медиа-блок (Aspect Ratio 1:1 или 4:3, `rounded-2xl`, `overflow-hidden`):**
   - Фоновое изображение товара с плавным зумом при ховере (`group-hover:scale-105 transition-transform duration-500`).
   - Верхний левый угол: бейдж `Выбор гостей` (`rounded-full`, белый полупрозрачный фон, мелкий жирный текст).
   - Верхний правый угол: кнопка `В избранное` (сердечко, круглая кнопка с легкой подложкой или контуром).
   - Индикаторы слайдера / пагинации (если фото несколько).

2. **Информационный блок (ниже фото, `pt-3`):**
   - **Строка 1 (Flex justify-between):**
     - Заголовок товара (`text-[15px] font-semibold text-slate-900 truncate`).
     - Рейтинг (`flex items-center gap-1 text-sm font-semibold text-slate-900`, иконка звезды).
   - **Строка 2:** Вторичное описание / даты / параметры (`text-sm text-slate-500`).
   - **Строка 3:** Стоимость (`text-[15px] font-semibold text-slate-900 mt-1`).
   - **Строка 4 (для корзины):** Кнопка «В корзину» или счетчик количества `[-] 1 [+]`.

## 7. Правила создания компонентов и кода

1. **Единый синтаксис компонентов:**
   - Функциональные компоненты с именованием в `PascalCase` (`ProductCard.jsx`, `CartDrawer.jsx`).
   - Имена файлов строго совпадают с именем экспортируемого компонента.
   - Один компонент — один файл.
   - Экспорт по умолчанию (`export default ProductCard`).

2. **UI-компоненты строго в `src/components/ui`:**
   - Компоненты в папке `ui` не должны знать о предметной области «корзина» или «каталог». Они принимают только чистые пропсы (`variant`, `size`, `children`, `onClick`, `className`).
   - Предметные компоненты помещаются в свои папки: `components/product/`, `components/cart/`.

3. **Соблюдение дизайн-токенов:**
   - Запрещено использовать случайные значения вроде `text-[#123123]` или `rounded-[7px]`, если есть токен Tailwind.
   - Всегда используем установленные скругления: `rounded-2xl` для карточек, `rounded-full` для бейджей.
   - Для текста используем `text-slate-900` и `text-slate-500`.

4. **Доступность (A11y):**
   - Интерактивные кнопки без текста должны иметь `aria-label` (например, `aria-label="Добавить в избранное"`).
   - Все кликабельные элементы должны иметь видимый фокус-стиль (`focus-visible:ring-2 focus-visible:ring-slate-900 focus-visible:outline-none`).
   - Картинки обязаны иметь осмысленный атрибут `alt` (или `alt=""` для чисто декоративных).

5. **Моковые данные и чистота:**
   - Все моковые данные выносятся в папку `src/data/`.
   - В компонентах не хардкодятся тяжелые статические массивы.
